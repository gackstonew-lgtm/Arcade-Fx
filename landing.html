  1. Tap the Browser Menu (3 vertical dots) in the top-right corner.
  2. Tap Add to Home Screen or Pin to Workspace.
  3. Confirm by clicking Install.

How to Install on Desktop (Windows / Mac):

  1. Click the Install Icon 💻 in your browser address bar (top right).
  2. Or open browser menu (3 dots) → select Save and Share → Install Arcade FX...
